# Guildie Agent Workflow & Execution Standard

This skill codifies the recommended pair-programming and autonomous agent development protocol.

## When to Activate
Activate this skill when starting any new feature, major bugfix, database expansion, or system release.

---

## The 6 Phased Steps

### Step 1: Deep Research
- Ingest repository architecture, directory structures, schemas, and runtime configurations.
- Verify existing database schemas using `PRAGMA table_info`.
- Review recent commit histories and open issues to understand context.

### Step 2: Skills & Institutional Memory
- Store recurring design patterns, user preferences, and domain rules as skills or memory files.
- Ensure that established standards (e.g. data isolation, zero unconstrained loops) are never forgotten across sessions.

### Step 3: Affirmative Vision & Autonomous Liberty
- State requirements positively: emphasize the desired user experience, seamless gameplay integration, and visual polish.
- Grant agents creative freedom to evolve existing code to match the theme and elevate the solution.
- Avoid micromanaging negative constraints—allow the agent to engineer an elegant, robust architecture.

### Step 4: Plan as Execution Log
- Author a dedicated Markdown plan before modifying code.
- Structure it with clear, phased milestones and task checkboxes.
- Keep the plan synchronized with real-time execution progress so it becomes a historical execution log.

### Step 5: End-to-End Buildout (Deferred Testing)
- Build the entire feature across all layers in a coherent pass.
- **Do not stop to run tests after every single line:** save testing for the end to preserve velocity and high-level architectural coherence.
- If delegating to subagents, assign clearly partitioned tasks with unambiguous inputs and outputs.

### Step 6: Batch Verification & Text-Based Visual Pass
- Run unit tests, fuzz suites, and static analysis in batch.
- Perform a **Text-Based Visual Pass** on the local dev environment:
  - Render ASCII or text-based mockups of UI components.
  - Review Discord embed hierarchies, color contrast, and field layouts.
  - Inspect in-game addon frame coordinates, font strings, and tooltip wrapping.
